# Grove Camp - WebGL build

Built from `Assets/DuckGame/Maps/V12/Generated/ExpeditionHub.unity`
Unity 2022.3.62f3c1

## Controls

```
WASD move | Shift sprint | Space jump | Ctrl slide
Mouse aim | Right mouse hold aim down sights | Left mouse fire
F interact | Tab toggle HUD | Esc release mouse
```

Serve this folder over HTTP; opening index.html from disk will not work.

```
npx --yes serve .
```
